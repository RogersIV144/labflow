# LabFlow 0.3.0 人工测试指南

建议先用新解压的分享包测试，避免修改自己的正式学习资料。需要 Node.js 22+；Windows 双击 `Start-LabFlow.cmd`，Mac 双击 `Start-LabFlow.command`，打开终端显示的本机地址。3D 测试不要求登录 AI。原有训练与模型接入的测试继续见 [0.2.1 指南](manual-testing-0.2.1.md)。

## 8 分钟核心检查

| 用时 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 分钟 | 笔记本窗口约 1280×720，打开 WB「学习 → 实验场景」。 | 能看见播放和重置；页面不横向溢出。阶段栏可切换；文字可辨认。 |
| 1 分钟 | 跳到「转膜」，点「当前操作」和「仅看当前器材」，旋转、缩放，再点「俯视」「全景」。 | 转膜器材完整入镜，独立视图没有其他器材遮挡；拖动不会误开说明；全景恢复所有器材。 |
| 1 分钟 | 转膜重置后用 0.5× 播放，中途暂停；选第三项，再回看第一项，重置。 | 暂停后进度不再增加；手动回看有效；第三项合拢、第一项展开；重置为 0/3 且夹层展开。动画不是实验操作计时器。 |
| 1 分钟 | 完整播放转膜一次，再切「封闭」。随后直接跳到其他步骤的末项。 | 完整播放数只增加一次；新步骤从 0 开始；跳到末项不会伪造完整播放。演示不增加独立训练成绩。 |
| 1 分钟 | 在「封闭」点「流程与笔记」，保存一条测试笔记；返回场景，点「回忆这一阶段」。 | 详情是「封闭」，可找到附图/修订；练习阶段是「封闭与抗体孵育」，不是误回样品或整体阶段。 |
| 2 分钟 | JTC 依次查看「记录联合功率谱 → 回显功率谱 → 相关读出」，点击各自操作项并回退进度。 | 第一轮采集前为等待，采集后为功率谱；回显步骤的第二项把输入换成功率谱；相关读出第二项后才显示相关结构；回退同步恢复二维图与三维屏幕。 |
| 1 分钟 | JTC「准直」改变偏差，再重置。仅使用 Tab、Enter 和方向键操作器材栏、速度、进度和参数滑块；进入专注模式后按 Esc。 | 近远光斑随偏差变化；重置回到初始状态。无需精确点击 3D 器材也能操作；Esc 退出专注。 |

## 仍需真人 / 实机确认

以下项目不能由本次 Mac 自动化结果替代：

1. **Windows 启动与显卡兼容性（3 分钟）**：在实际 Windows 笔记本解压分享包，启动后分别进入 WB、JTC。旋转和切换十次，观察黑屏、闪烁、纹理缺失及崩溃。记录 Windows 版本、浏览器版本、显卡、显示缩放比例；启动失败请保留终端错误文字。不要附上 token 或密钥。
2. **触控板和鼠标手感（2 分钟）**：分别拖动画布、双指滚动缩放；旋转结束后点击器材。预期手势容易控制、点击与拖动可区分、停止后镜头不会持续漂移。若过快/过慢，记录设备和哪一种手势。
3. **性能与减少动态（3 分钟）**：在浏览器任务管理器或系统活动监视器中比较播放与静止 30 秒后的负载，再切到其他标签页。预期静止/后台负载明显下降。开启系统“减少动态效果”后刷新：操作项仍可切换，器材循环运动停止、镜头直接到位。本轮没有测量 FPS 或续航，不以“感觉流畅”代替数字性能报告。
4. **WebGL 不可用 / 恢复（可选，测试用浏览器）**：若设备本身不支持 WebGL，核对文字导览仍能用。开发者可用浏览器开发工具模拟 WebGL 上下文丢失，检查出现提示后「重新加载三维场景」能恢复。不要为此改动主力浏览器的安全设置；此项本轮仅检查代码路径，未实机模拟。
5. **教学理解（找一位未看过流程的队友，5 分钟）**：先观察，再切回忆训练，让对方独立说出转膜方向，或两次 JTC 测量分别以什么为输入。记录哪里看不懂、文字与模型是否容易对应。先让对方回答，再主动给提示；不要把看过动画等同于掌握。
