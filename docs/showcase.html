02

The shortcut we refuse 我们拒绝的捷径

AI makes answers free. When the answer arrives too early, learning stops. AI 让「得到答案」变得毫无成本。但答案出现得太早，学习就结束了。

03

The learning loop 学习闭环

01 / EXPAND

展开学习

One root becomes stages and steps; each node carries action, rationale, checkpoint and source.总块展开到阶段与步骤；节点含操作、原因、检查点与来源。

02 / RECALL

回忆重建

Detail fill → order reconstruction → blank-canvas rebuild, with separate drafts.细节补全 → 顺序重建 → 空白重建，草稿各自保留。

03 / ASSESS

检验与点评

Verdict only by default; broad hint, specific cause, answer and critique are requested.默认只给判定；提示、定位、答案与点评逐级请求。

04 / REPLAY

实操重放

Stepwise navigation at the bench; notes and images live on the current node.实验现场逐步导航，笔记与图片挂在当前节点。

One shared, versioned protocol reference throughout. 贯穿始终的是同一份版本化实验参考：旧题沿用旧版快照，判答结果绑定当次提交。
04

What makes it different 重点与优势

◆

Help never takes over 帮助不接管学习

A request marks the attempt assisted until a fresh independent round begins.求助标记该回合为 assisted，直到主动开启新的独立回合。

◆

One design, two disciplines 两套案例，一个机制

WB for order and interpretation; JTC for alignment with real Fourier optics.WB 考顺序与解读；JTC 把光轴调节接到真实 FFT 求解。

◆

Local-first 本地优先

Web app, reference, notes and drafts stay on the machine; deterministic checks run locally.网页、参考、笔记都在本机；可确定的检查本地判定。

◆

Honest degradation 不假装 AI 可用

A timeout preserves the answer and labels the fallback instead of inventing a verdict.超时保留作答并明确标注降级，不伪造模型评价。

◆

Review becomes UI 反馈变成界面决策

Transfer orientation and blocking order became judgement tasks with visible consequences.转膜方向、封闭先后从「确认」改为「判断」并显示后果。

◆

Agent-ready 可被外部 agent 接入

MCP stdio exposes context, checks, hints, notes, images and reference revisions.MCP 暴露上下文、检查、提示、笔记、图片与参考修订。

05

Evidence, not adjectives 研究依据

The report records what held up and what has not been verified yet. 报告不只描述功能，也记录了哪里成立、哪里还没被验证。

Supported / 已被支持

  • Progressive disclosure + guided fill-in produced real recall on second use.渐进披露与引导填空带来真实回忆：第二次无需重学即可回忆步骤、仪器与操作。
  • 92 automated tests passed on 2d0cd48; build, type check and HTTP/MCP integration clean.92 项自动化测试全通过，构建、类型检查与集成检查干净。
  • Domain findings became interface decisions; critique supplied the reasons a verdict could not.领域反馈转成界面决策；详细点评补上了判定给不了的理由。

Not yet verified / 尚未验证

  • Explanation is the weak point: steps can be rebuilt but not justified; the checker measures wording.解释层最薄弱：能重建步骤却说不清原理；检查器量的是措辞。
  • Whether learners return to independent work after an assisted round is untested.求助后是否回到独立练习，本轮没有数据。
  • Blank reconstruction felt premature; some features were never discovered.空白重建对首次学习者过早；部分功能存在可发现性问题。
