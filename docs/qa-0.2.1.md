# LabFlow 0.2.1 修复复测

2026-10-16，针对 [0.2.0 验收](qa-2026-10-16.md) 发现的缺口继续修复。三个子 agent 负责前端、教学边界与人工指南；本轮实际浏览器操作由主 agent 使用 CUA 完成，不将子 agent 的代码检查记为亲自操作界面。

环境为 Mac 上 1280×720 的应用内浏览器。4341 使用真实 Codex（界面当前模型 `gpt-6.1-sol`），4342 指向不存在的 Codex 程序模拟不可用。均使用临时数据目录，没有修改正式学习数据或退出账号。

## 自动验证

- 50 项单元测试、TypeScript 检查与生产构建通过。覆盖动态高度避障、旧连线跨行与反向端点、单点引用真实性、单项遗漏、拒绝整题泄漏、概念范围、快照竞态、固定评分标准等。明确要求只判对错或禁止解释的聊天请求另有本地边界和接口回归，避免因出现概念关键词而主动讲解。
- 隔离 HTTP/MCP 集成通过：草稿与端点保存、8 个工具、检查快照、取消与重复提交、参考修订、配图、模型设置及生成回退。该测试使用合成 harness 验证传输，不作为真实模型或 CC Switch 证据。
- 分享包另提供独立解压检查脚本，检查无项目依赖运行、离线判题与 MCP；Windows 启动和真实 HTTP 服务不由 Mac 的包测试替代。

## 保留给人工的项目

1. **原生图片拖放**：本轮 CUA 拖动仍只选中图片，附件数为 0；点击归位后为 1。无法区分应用问题和自动手势限制，故不记原生拖放通过。请在 Windows Edge/Chrome 用日常鼠标或触控板实际测试。
2. **真实 CC Switch / HTTP 服务**：没有访问队友的配置或凭据。协议单元测试不能证明其实际代理支持 JSON Schema、所选模型和重启后的请求。
3. **Windows 真机**：未在 Windows 执行分享包，也没有伪造未登录环境。现成未登录/无 CLI 环境可抽样测试，无需退出账号或删除凭据。
4. **教学内容全面验收**：本轮真实模型聚焦封闭液题；其余题和生成变式仍需按参考抽样，不能宣称全部 issue 全面验收或学习效果成立。
