# LabFlow 0.2.1 修复说明

本版继续处理 0.2.0 界面验收暴露的问题。人工复测步骤与通过标准见 [测试指南](manual-testing-0.2.1.md)。

- **流程布局与操作空间（#2、#3）**：学习图的跨行连线从侧面绕行；练习连线保存具体连接点，刷新、撤销和跨阶段恢复保留端点。旧草稿仍可恢复。新增「展开画布／退出专注」，收到提示或点评时自动显示学习伙伴。
- **单点提示（#6）**：「再具体一点」绑定最近已检查的提交，只引用一处原句或指出一项遗漏并解释原因。同一提交重复点击保持同一点。修改答案后要求重新检查；请求期间显示核对状态。无法可靠核对时明确说明，避免用通用文案冒充具体提示。
- **概念聊天（#6）**：明确的单概念问题可直接获得有限解释，使用当前题目冻结参考中的摘录。当前覆盖封闭液与一抗稀释液、归一化、重复、线性范围、膜预处理；未覆盖或多概念问题明确说明限制，不自动展开整题答案。
- **AI 情境（#6、#9）**：「AI 出题」和新一轮回忆保留选中的情境，「换一题」负责轮换。模型仅生成题面，原评分标准由服务器保留；依据核对失败时明确回退。
- **模型设置（#4、#7、#8）**：Codex 不可用时不再显示误导性的 HTTP 自定义选项；HTTP 模式标明配置状态需由实际请求验证。

默认检查仍只显示判定；详细点评和完整参考须主动请求。概念解释计入辅助练习。没有新增独立 agent 框架、审核系统或历史聊天功能。

升级前停止旧服务并备份原目录，将 `.labflow` 复制到新解压目录后启动。分享原始 `LabFlow-0.2.1-team.zip`，不要重新打包使用过的数据目录。

Windows 真机、真实 CC Switch 服务和原生日常浏览器拖放仍需按指南验证。模型生成与评价的抽样通过不代表全部题目和所有措辞都已验收。
