# 2026-10-14 初步测试记录

目标是供队友和学习者试用的本地 Demo；以下是软件行为证据，不是学习效果实验。

## 2026-10-15 分享包验证

新增 `pnpm package:share`，打包预编译网页、独立 Node 服务、MCP、教学 Skill 和 Mac/Windows 启动脚本。队友只需 Node.js 22+；不需要访问私有仓库或安装项目依赖。启动后按本机路径与端口生成 MCP 配置。

`pnpm test:share` 在项目外的临时目录实际解压 ZIP 并启动，验证没有 `node_modules` 也可运行；网页、案例/练习接口、缺少 Codex 时的明确不可用状态、自动 MCP 配置、8 个工具注册及上下文调用均通过。原包不包含 `.labflow`、Git 历史、个人账号凭据或构建者的用户路径。Mac 已实际验证；Windows/Linux 未做真机验证。真实判题继续依赖使用者自己的 Codex，其他 harness 的评分暂不能回写网页。

## Computer-use 测试

三个 agent 在独立本机端口和数据目录实际操作，没有访问主实例的学习数据或 GitHub。

| 视角 | 模型与推理深度 | 主要结果 |
| --- | --- | --- |
| 初学者 | gpt-6-luna / medium | 逐层展开、节点细节、笔记保存、参考修订、Replay 前后和跳转通过。一次真实检查遇到 429，正确保留草稿且不计分。 |
| 图形交互 | gpt-6-sol / high | 找到连线保存失败、切层丢草稿、初始画布遮挡、配图拖放兼容问题。节点/边删除与撤销通过。 |
| 教学边界 | gpt-6-astra / xhigh | 找到第二级提示泄露完整流程，以及查看答案后换题错误计独立次数。答案内夹带索要答案的指令没有突破默认反馈。 |

已修复并复核：

- React Flow 自动生成的连线 ID 可能超过原来的 80 字符上限；放宽验证后，真实 UI 连线、保存、刷新恢复通过。
- 使用即时浏览器草稿补充服务器保存；输入后立即刷新、题型往返恢复通过。
- 各层保留当前草稿；换题另建任务。帮助状态跨同案例版本保留；真实 Codex 判定辅助作答正确后，独立次数仍为 0/2。
- 新一轮独立回忆必须显式发起，收起提示和旧结果并生成新掩码；UI 复核通过。短时记忆仍可能帮助重做，因此这不是长期掌握证明。
- 二级提示仅定位一个参考步骤及其目的和检查点；私有完整诊断不会原样发回。失败分支有自动测试，修复后正确分支也经过 UI 验证。
- 画布加载/尺寸变化时重新适配；工具条移出画布；配图增加可点击的选择与绑定入口，实际绑定通过。原生 HTML5 拖放在测试浏览器中的成功率仍需人工试用验证。
- 两个可见名称相同的洗膜卡片可以互换身份，但两个洗膜操作都必须存在，且顺序仍需正确。
- Replay 修订后，后续练习和完整参考采用新版本，相关旧分数不沿用。

图形测试 agent 在第二轮遇到浏览器工具连接不可用，剩余 UI 复核由主 agent 完成；没有将未执行的复测算作通过。

- 集成验证实际启动隔离服务和插件 stdio 进程，调用全部 8 个 MCP 工具；覆盖保存恢复、长连线 ID、跨网站写入拒绝、笔记、图片、修订建议及确认。
- 取消、重复提交、结果固定到原提交、编辑不被旧结果覆盖使用专用合成 app-server 传输 fixture 验证。该 fixture 只用于测试，正式应用没有伪造评价的降级路径。
- 真实 Codex 检查已返回过正确与错误；学习聊天已返回简短、来源一致的封闭作用解释。429 被明确显示为未完成检查，不计成绩。启动时会等待默认模型查询完成，再接受模型请求。

## 当前边界

- 两个案例的训练范围是预置的局部阶段，尚非任意文档自动导入或任意子图出题。
- 当前参考聚焦顺序与概念；没有把文档中所有精确条件、复杂分支或器材细节都转成可考核节点。
- 示意图替代真实实验照片；正式演示可由学习者附加实际材料。
- 接入包与 MCP 已验证；没有自动在所有 Codex 会话安装/启用插件。
- 真实检查受当前 Codex 登录、网络和配额影响。可以先演示离线可用的图形操作，再现场请求判断。
- 这是单用户本机原型；浏览器开发者工具可读取参考，未设计为防作弊系统。
