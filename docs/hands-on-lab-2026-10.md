# 动手实验交互（2026-10-23）

本轮在现有 WB 与 JTC 三维器材上增加「动手操作」模式。用户的取液、加样、启动电源、调节旋钮和采集动作更新独立实验状态，三维器材、二维观察图与操作台读数使用同一状态。

## 入口与操作

进入「学习 → 实验场景 → 动手操作」。右侧为实验操作台，三维画面默认聚焦当前器材；可切换全景、俯视或单件近景。三维热点提供直接操作，按钮、滑块和增减按钮提供另一种输入方式。

### WB：从加样到成像

1. 在「移液加样」设定体积，装新吸头，再点击源样品管或「从样品管吸液」。源管余量减少，吸头出现液柱。
2. 选择四个练习泳道之一，点击泳道或「向泳道加样」。吸头排空，目标孔位出现样品；退掉已使用吸头后，可换新吸头继续加样。
3. 在「电泳分离」合上槽盖并启动电源。条带随进度分离，可暂停、继续；空泳道不会凭空出现条带。
4. 电泳完成后进入「转膜检测」，检查凝胶与膜的顺序，完成转膜示意；再确认完成免疫检测示意。
5. 进入「曝光成像」，调整曝光并采集。图像使用本次各泳道的加样量；曝光改变后需要重新采集。

操作顺序由状态机约束：未装吸头不能吸液，吸头有液时不能再次吸液，已使用吸头需先弃去，目标容量不足时保留吸头中的液体并提示。运行时不能打开槽盖，开始迁移后不能追加样品。转膜需要完成电泳，成像需要完成转膜与免疫检测。

本练习从**已完成前处理的同一样品**开始，用四泳道比较加样量。免疫检测将「封闭 → 一抗 → 洗膜 → 二抗 → 再洗膜」合并为一次确认；详细操作仍可在「观看演示」逐步学习。练习设定为源管 200 µL、单次取液 5–30 µL、每泳道最多 30 µL，电泳时间经过教学压缩。这些数值用于交互反馈，不构成实际仪器量程、胶孔规格或实验 SOP。

### JTC：调光路与两次测量

1. 开启激光器，通过「水平微调 X」「垂直微调 Y」调整光斑位置，通过「准直调节」比较近远光斑大小。可使用滑块、增减按钮，或左右拖动三维旋钮。
2. 观察近远光屏和示意透过量。偏轴会削弱后续光束；准直偏差会影响输出结构的清晰程度。
3. 在「两次采集」装载双目标图，采集第一次联合功率谱。
4. 将已采功率谱回显到输入面，再采集相关输出。第一次结果的质量会继续影响第二次结果。
5. 调偏光路并重新采集，可比较结果变化。关闭光源后不能采新图，已有图像保留。

采集结果保存当时的 X、Y、准直和质量状态。之后转动旋钮只改变实时光路，不会追溯修改已保存图像；重新采集第一次功率谱会替换旧谱并清除旧的第二次结果。

光斑、示意透过百分比、谱图和相关输出采用定性关系生成。旋钮刻度为相对练习量，不是实际位移、角度、测量功率或识别置信度，也不替代设备校准。

## 状态与演示的边界

- 「观看演示」仍使用步骤播放状态；「动手操作」使用独立状态。播放或跳转演示不会自动完成加样、转膜或采集，也不会修改手动操作结果。
- 同一实验中的步骤切换、观察器材和两种模式切换保留手动状态。离开动手模式时，正在运行的电泳暂停。
- 当前实现将状态放在 `LabExperience` 组件内存中。刷新、离开实验场景进入流程图或回忆训练，以及切换实验导致组件卸载时，会重置操作；没有写入本地数据库或浏览器持久存储。
- 页面隐藏期间不推进手动电泳计时；返回后不会把后台经过的长时间补算进实验。重置按钮只清空对应实验的状态。
- 动手操作不计入回忆训练成绩，示意图不作为实验测量证据。

## 实现位置

- [interaction-state.ts](../src/lab/interaction-state.ts)：WB 与 JTC 事件、顺序约束、数值边界、快照和光斑指标。
- [HandsOnPanel.tsx](../src/lab/HandsOnPanel.tsx)、[interaction.css](../src/lab/interaction.css)：操作台、实时读数、二维观察和保存结果。
- [LabExperience.tsx](../src/lab/LabExperience.tsx)：演示/操作模式隔离、步骤与器材导航、电泳进度计时。
- [LabScene.tsx](../src/lab/LabScene.tsx)：射线拾取、三维热点和旋钮拖动；操作旋钮时暂停镜头旋转，结束后恢复。
- [scene-wb.ts](../src/lab/scene-wb.ts)、[scene-optics.ts](../src/lab/scene-optics.ts)：将手动状态应用到器材、液柱、泳道、膜、光路与成像纹理。

## 验证记录

- 自动测试共 **78 项通过**，包含新增的 14 项手动状态测试。
- 新增测试覆盖：吸头与操作顺序、取液和排液守恒、残液弃去、源液不足与泳道容量、无效数值拒绝、运行门控、暂停/继续、迁移结束、转膜与免疫检测门控、曝光重采、光轴与准直影响、两次采集快照保持及单实验重置。
- TypeScript 与生产构建通过。三维延迟加载块约 648 kB / gzip 172 kB，仍保留 Vite 大块提醒；没有新增运行时依赖。
- 实际浏览器 WB 验收：直接点击三维吸头盒、源样品管和泳道完成加样；20 µL 与 5 µL 对照；无吸头/未合盖拦截；暂停与继续；转膜后夹层合拢；免疫检测后成像；改变曝光后重新采集；跨步骤及演示切换保留结果。
- 实际浏览器 JTC 验收：鼠标拖动三维水平旋钮使 X 从 0 变为 −20、示意透过从 100% 变为约 41%，同时保持相机观察角度；调节三轴；空输入/关光源拦截；偏轴弱图、归中后重新采集及两次测量；调节后已保存快照不变；重置回到调节页。
- 布局检查覆盖 1280×800 与 390×844；窄屏 document 宽度与 scrollWidth 均为 390，增减按钮可操作。未对真实触屏设备、多指手势、帧率或显卡兼容性进行测试。
