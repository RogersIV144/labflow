# 交互实验场景

本次功能在 LabFlow 既有学习与 Replay 中加入可操作的三维实验台和二维结构示意，覆盖 Western Blot 的 19 步与联合傅里叶相关（JTC）的 8 步。流程图和回忆训练仍可从原入口使用。

## 使用

1. 按 [README](../README.md#启动) 启动，打开 <http://127.0.0.1:4317/>，选择实验后进入「学习」→「实验场景」。刷新可能恢复已有练习草稿；点击「学习」即可进入场景。
2. 拖动旋转、滚轮缩放；点击器材查看说明，并可定位相关步骤。「靠近当前操作」聚焦当前器材；右上按钮可重置视角、切换俯视和放大场景。
3. 点击播放自动依次演示操作，暂停可停住演示；也可逐项点击「操作导览」。用上一步、下一步或底部「实验全程」跳转。
4. WB 可展开/合拢转膜夹层，并在成像步骤改变示意曝光；JTC 可调整光轴或准直偏差，观察近远光屏，以及双目标→联合功率谱→回显功率谱→相关输出的变化。
5. 点击「流程图」查看层级关系；点击「去回忆训练」开始原有练习。已演示标记仅表示当前场景中走完操作，不是得分、掌握度或独立完成次数。

按钮与滑块使用原生 HTML 控件，可通过 Tab、Enter/Space 和方向键操作。操作导览与观察文字提供不依赖三维器材点击的路径；三维画布本身没有键盘逐器材导航。WebGL 初始化失败或上下文丢失时显示提示，操作导览仍可使用。

## 场景与视觉

沿用现有鼠尾草绿、奶油白工作区、字体和控件语言。深绿色舞台用于衬托浅色器材；学习内容保持明亮。宽屏并排放置实验台与操作导览，窄屏改为上下排列。底部步骤条可独立横向浏览，页面主体不应横向溢出。

| 实验 | 三维内容 | 二维辅助 |
| --- | --- | --- |
| WB · 19 步 | 试剂与样品、移液器、配平离心机、电泳槽、转膜夹层、孵育洗膜盘、成像仪；演示移液、分离、夹层贴合、结合与洗液交换 | 离心后上清/沉淀剖面、凝胶至阳极侧膜的转移方向、相对曝光与合成条带 |
| JTC · 8 步 | 激光器、近远光阑、空间滤波器、透镜、输入显示面与相机；显示元件位置、光路和第二次输入的替换 | 近远光斑、合成双目标、联合功率谱与两侧相关结构 |

界面明确标注「教学模型 · 非实测图像」「合成图像 · 结构示意」。器材比例、液体、粒子、光束和条带仅服务于概念解释。曝光滑块不是秒数，对准滑块不是实测误差；动画时长不是实验操作时长。不提供固定配方、转速、时间、温度等协议参数，具体条件依实验室确认方案与厂家说明。

## 实现与维护

- [App.tsx](../src/App.tsx) 通过 `React.lazy` 加载场景；学习/Replay 的场景与流程图共用当前步骤选择。
- [LabExperience.tsx](../src/lab/LabExperience.tsx) 管理操作序列、播放、视图、调整控件及二维 SVG/CSS 示意；[scene-data.ts](../src/lab/scene-data.ts) 为既有步骤 ID 增补器材、动作与观察说明。
- [LabScene.tsx](../src/lab/LabScene.tsx) 用 Three.js 程序化几何创建器材，用 Canvas 生成标签与信号纹理，使用 OrbitControls 旋转/缩放、射线拾取和透视/俯视/局部聚焦镜头。场景运行时不请求外部模型、图片、视频或 CDN 资产。
- [lab.css](../src/lab/lab.css) 将样式限定于场景区域及其工作区状态，包含窄屏布局、可见焦点和减少动态效果偏好。渲染器限制像素比，画布离屏或页面隐藏时跳过渲染；卸载时释放几何、纹理、材质与事件监听。
- 案例标题、摘要、原因、检查点与来源仍读取现有 `seedCases` 及当前参考版本。新增场景说明不替换原始参考，不写入评分规则。步骤覆盖应随 `lab.sequence` 与步骤 ID 一并维护。

科学关系补充核对参考包括 [Bio-Rad 厂商资料](https://www.bio-rad.com/webroot/web/pdf/lsr/literature/4006190b.pdf)、[Thorlabs 厂商资料](https://www.thorlabs.com/catalogpages/Obsolete/2021/P10D.pdf) 和 [JTC 相关公开论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9267976/)。这些是核对链接，场景不会在运行时加载其内容。

## 已知边界

这是教学交互原型，没有完整流体、分子、光学传播或实验设备物理仿真，也没有真实实验视频或照片。联合功率谱、相关输出及条带均为程序合成，不能用来定量、识别置信度或推断生物学结论。场景未验证学习成效、长期保持或真实实验操作能力；演示完成不增加独立训练成绩。低性能设备的帧率和更广泛的浏览器兼容性仍需后续验证。
